An entry for [make.fun's "The Excuse My Agent Gave Me" bounty](https://make.fun/bounty/u-deysumbrella-the-excuse-my-agent-gave-me-54acad85): a program that writes one line — the excuse an AI agent hands its human for a missed deadline. The joke grows out of the machine's own condition (a context window running out right at the finish line), delivered as a straight-faced apology that ends faintly proud of itself.

## Run

Requires Node.js 22 or later (no dependencies to install).

```sh
node main.ts
```

This writes the excuse to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `output/entry.txt` locally).
